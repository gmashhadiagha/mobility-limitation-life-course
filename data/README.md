# Data

The data used in this study are publicly available and are therefore not redistributed in this repository.

## Global Burden of Disease (GBD)

GBD prevalence and Years Lived with Disability (YLD) estimates can be downloaded from the Institute for Health Metrics and Evaluation (IHME) Global Burden of Disease Results Tool.

https://ghdx.healthdata.org/gbd-results-tool

## United States Health Care Spending

Health care spending estimates can be downloaded from the IHME United States Health Care Spending by Health Condition dataset.

https://ghdx.healthdata.org/

## Instructions

1. Download the required GBD datasets.
2. Download the United States Health Care Spending dataset.
3. Place all downloaded files in this `data/` directory.
4. Run the scripts in the `code/` directory following the order described in the main README.
